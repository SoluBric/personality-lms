# Course Reset v3 Package

This package is the proposed replacement course-system reference for the demo project.

Recommended reading order:

1. `00-document-and-code-migration-plan-v3.md`
2. `01-course-system-architecture-v3.md`
3. `02-course-catalog-v3.md` for human review
4. `02-course-catalog-v3.yaml` for canonical structured data
5. `03-demo-recommendations-v3.md`
6. `04-development-map-rules-v3.md`

The YAML contains 96 demo courses:

- 22 Strengths
- 36 Stress & Growth
- 18 Fortification
- 20 Team

The old course/catalogue documents should be archived or removed according to the migration plan before Codex is asked to refactor the application.
