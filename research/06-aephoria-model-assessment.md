# Aephoria Model Assessment

## What Differs From the First Content Pack

The first pack already used weighted scores across all nine Enneagram types and highlighted the top three. The Aephoria-style approach changes the product language and hierarchy:

- First pack: top three weighted patterns.
- Aephoria-style model: main type plus ordered trifix.
- First pack: traditional type labels with capacity names.
- Aephoria-style model: vivid persona headings such as "Adaptive Diplomat" and "Tough Protector".
- First pack: no instinct stack.
- Aephoria-style model: instincts may be part of the result profile.

The underlying data does not need to change much. The interpretation layer changes.

## Recommended Incorporation

Incorporate the Aephoria-style model, but keep it lightweight.

### Use Strongly

- Main type as the primary result.
- Ordered trifix as a visible signature, for example `3-8-5`.
- Aephoria-style headings as the user-facing type names.
- Traditional labels as secondary reference labels.
- Course recommendations tied to the main type, trifix, weaker capacities, and team gaps.

### Use Lightly

- Instinct stack as a small profile chip and scenario modifier.
- Center balance as a supporting insight.
- Trifix explanations as short interpretation cards, not exhaustive archetype pages.

### Defer

- Full 27 subtype catalog.
- Full 27 trifix archetype catalog.
- Cross-product of 27 subtypes and many trifix combinations.
- Strong claims that trifix or instincts are psychometrically precise.

## Literature Check

The modern literature is mixed but usable for a demo if claims stay careful.

Core Enneagram type work has some peer-reviewed support as a workplace and self-development framework, including exploratory work connecting Enneagram types with work-related variables. Some newer scale-development studies report acceptable reliability and validity for specific instruments. Other studies find weak psychometric support for some open Enneagram scales. This means the app should not present its results as diagnostic or highly predictive.

Trifix / Tritype and instinctual stackings are common in contemporary Enneagram communities and coaching systems, especially in Katherine Fauvre's Tritype work and instinctual subtype research. However, these layers are more proprietary and less independently standardized than the core nine-type model. They are good for interface richness and reflective coaching, but should not be the first demo's evidence-heavy engine.

## Product Decision

Use this model:

1. Main type: highest score, displayed with Aephoria-style heading.
2. Trifix: top three scores in order, displayed as the user's pattern signature.
3. Instinct stack: optional profile context, displayed as a small chip.
4. Course recommendations: generated from main type, trifix calibration, weakest capacity, team gap, and user goal.

This gives the demo the visual and conceptual richness of the Aephoria approach while keeping the LMS content manageable.
