# Personality LMS Research Pack

This folder contains the first-stage content research for a demo web app that combines personality assessment outputs with LMS-style personal development pathways.

The current focus is the Enneagram because it has a well-known nine-type structure and enough public literature to support meaningful demo content. The content should be treated as developmental and reflective, not clinical or diagnostic.

## Working Assumptions

- Users have already completed an assessment.
- Each user has weighted scores across all nine types, with a main type and ordered trifix emphasized.
- Instincts can be included as a lightweight secondary lens, but should not drive the first demo's primary recommendation engine.
- The app does not need to explain itself to public users; it is a guided demo for invited viewers.
- The later LMS can recommend courses based on dominant type, blind spots, underdeveloped type capacities, and team context.
- The strongest product direction is not "you are this type", but "these are current patterns and capacities you can develop".
- These documents are working foundations, not locked specifications. Expect recommendation rules, labels, and interface hierarchy to evolve once the app is interactive.
